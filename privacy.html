2. 처리 위탁과 제3자 제공

  • 결제 처리: 토스페이먼츠 (결제 승인·정산)
  • 인프라 운영: Cloudflare (웹 호스팅·보안), GitHub (정적 페이지 호스팅)
  • 본인인증(도입 시): 본인확인기관과 인증 중개사 [계약 확정 후 상호 기재]

위 수탁자 외 제3자에게 개인정보를 제공하지 않습니다. 법령에 근거한 요청은 예외로 합니다.

3. 학생 음성·영상의 처리

면접 스튜디오의 답변 녹음·녹화 파일은 채점과 첨삭에만 사용합니다. 음성 전사(STT)는 연구소가 직접 운영하는 장비에서 처리하며, 외부 클라우드 음성인식 서비스로 원본을 전송하지 않습니다. 파일은 보유 기간(90일)이 지나면 자동 파기합니다.

4. 정보주체의 권리

회원은 언제든 자신의 개인정보를 열람·정정·삭제·처리정지 요청할 수 있습니다. 요청은 admin@hyunhak.com 으로 접수하며, 지체 없이 처리 결과를 알립니다. 회원 탈퇴는 마이페이지 또는 이메일로 요청할 수 있습니다.

5. 안전성 확보 조치

  • 비밀번호는 복호화할 수 없는 방식(PBKDF2)으로 암호화하여 저장합니다.
  • 전 구간 HTTPS 암호화 통신을 적용합니다.
  • 관리자 화면은 별도의 이중 인증 뒤에 둡니다.
  • 결제카드 정보는 연구소 서버에 저장하지 않습니다(결제대행사 처리).

6. 쿠키

로그인 상태 유지를 위한 필수 쿠키만 사용합니다. 광고·추적 목적의 쿠키는 사용하지 않습니다. 방문 통계를 도입하는 경우 이 방침에 먼저 반영하고 고지합니다.
