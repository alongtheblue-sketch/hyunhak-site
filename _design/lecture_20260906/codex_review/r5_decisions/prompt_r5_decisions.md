## 항목 1. LC-2 맛보기 6본 편 선택과 절단
사실:
- 강좌 6개(common, yonsei-hum, yonsei-sci, yonsei-intl, korea-hum, korea-sci)마다 맛보기 1본. 유료 강의에서 45초 지점부터 75초를 잘라 로그인 없이 공개(mp4 960px 약 1.4MB, VTT 자막, 포스터 jpg).
- 원천 편 = common L0-2 개수계약(1,229s), yonsei-hum L1-3 480초배분(1,110s), yonsei-sci L1-5 자연밑줄기준(1,137s), yonsei-intl L2-1 층위차이(1,106s), korea-hum L3-2 자료해석1 표(1,173s), korea-sci L4-1 직렬구조(1,010s). 각 편은 S01 인트로 + 본절 7~8개 + S09 마무리, 절 길이 90~180초.
- 실측: 6본 전부 45초 지점이 S01 인트로 안(각 편 S01 은 85~114초까지)이고 문장 중간에서 시작한다. 예 common 첫 큐 "답변 첫 문장에서 말한 개수가 채점자와 맺는 약속이라는 뜻인데," / korea-sci "준비 21분의 첫 90초," / yonsei-sci "둘째, 밑줄이 말하는 것과 말하지 않는 것을 가르는 법이고요."
- 절 경계는 정렬 지도(align_map.json)에 초 단위로 있다. 예 L0-2 S02 시작 114.758s 첫 문장 "학생들이 면접 준비하면서 제일 많이 듣는 말이 뭐냐면? 두괄식으로 말하세요예요." S03 218.338s "개수 계약의 정의". 자막 srt 도 같은 시각 축.
- 상세면 캡션이 편을 이름으로 박는다("공통 풀이 2편 개수 계약 발췌, 1분 15초", "단위 강의 3편 480초 배분 발췌"). 목차에서 그 편에 맛보기 배지가 붙고 "맛보기" 버튼이 #sample 로 간다. 편을 바꾸면 캡션, SAMPLE_ID, 배지가 같이 바뀐다(빌더 _tools/build_lectures.py 의 SAMPLE, SAMPLE_ID 두 dict).
- 재절단 비용: 로컬 ffmpeg + srt 시각 이동 + 포스터 + 빌더 재빌드 + 게이트 + 커밋. 실돈 0. 배포는 건우 `!`.
- 편 선택 당시 이유: 각 강좌에서 "그 강좌의 핵심 개념이 가장 잘 드러나는 편"을 골랐다(1강 인트로 대신 2~3강 본론). 판매 페이지의 목적은 "말하는 속도와 순서를 사기 전에 확인"이다(페이지 문구).
선택지:
 A. 편 유지, 시작점만 절 경계(S02 또는 S03 시작)로 옮기고 75초 유지
 B. 편 유지, 절 하나를 통째로(90~180초) 공개
 C. 각 강좌 1강(L0-1, L1-1, L1-1?, L2-1 은 이미 1강, L3-1, L4-1 은 이미 1강)으로 교체 + 절 경계 절단
 D. 전편 교체(새 편 선정 기준을 네가 제시)
답할 것: 선택 + 절 경계를 S02 로 할지 S03 로 할지의 규칙(예: "인트로 다음 첫 본절 시작") + 길이 + 자막 처리 + 포스터 프레임 시각 규칙.
