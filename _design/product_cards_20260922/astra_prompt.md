너는 hyunhak.com(현학적 연구소, 대입 면접 준비 상품 판매) 홈 상품 카드 3장의 시니어 UI 디자이너이자 심사자다. 첨부 이미지는 현재 라이브(cur)와 개선안 A2, B, C 를 1440px 폭에서 같은 조건으로 렌더한 것이다(행사 30% 할인 활성 상태, 카드 1과 2 는 정가 취소선과 할인가 2단, 카드 3 은 할인 없음).

배경: 소유자가 "카드 높이가 제각각이고 디자인이 나쁘다" 고 했다. 실제 결함 = 카드마다 본문 길이가 달라 가격 시작선과 CTA 버튼 높이가 어긋났고, 카드 2 에만 CTA 아래 링크가 하나 더 있었으며, 카드 3(의뢰) 가격이 잘못 적혀 있었다.

이번 변경 (전 안 공통):
- 마크업: 가격 행들을 .r2-card-prices 로 감싸고, 카드 2 의 링크를 본문 블록 끝으로 옮겨 CTA 행을 세 카드 동일 구조로 맞췄다.
- 카드 3 가격 = 1개 학교 100,000원 / 학교 추가 1곳마다 +50,000원 / 첨삭과 꼬리질문, 학교마다 +100,000원 (3행).
- A2 = CSS Subgrid 5행(대상, 제목, 본문, 가격, CTA) 카드 간 동기화. 제목은 행 아래 정렬 + max-width 7.5em 으로 세 제목 모두 두 줄. 가격 블록은 행 시작에, CTA 는 행 끝에. 카드 3 의 "학교마다" 는 정가 줄과 같은 자리의 소형 회색 단위 줄(카드 1, 2 의 정가 취소선과 같은 2단 리듬).
- B = A2 + 가격 블록을 mat 바탕 패널로 묶고 행 사이 헤어라인, 라벨을 회색 소형으로.
- C = A2 + 정가 취소선과 할인가를 한 줄에(금액 h5).
토큰은 base.css 기존 것만 쓴다(Pretendard 700 tabular-nums 금액, seal=할인가 색, mat=옅은 바탕, 8pt 간격 체계). 금액 서체는 어제 확정이라 바꾸지 않는다.
