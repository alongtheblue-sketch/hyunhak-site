# design-critic 브리프 — hyunhak.com 홈 상품 카드 3장 (디지털 UI, 2026-09-22 s5)

용도(G1): 판매 사이트 홈 fold 바로 아래 상품 카드 3장. 방문자 = 대입 면접 준비 수험생과 학부모. 목표 = 3 상품의 차이와 가격을 10초 안에 읽고 CTA 로 진입. 매체 = 웹 반응형(1440 / 1024 / 390).
토큰: base.css 고정(Pretendard 700 tabular-nums 금액, seal #9E2B22 = 할인가, ink, gray, mat #EBE4D4, 8pt 간격, r-md 4px). 무드 소싱 생략 사유 = 기존 hyunhak 토큰 체계(09-08 R3 재디자인 산출) 안의 수리.

결함(라이브, shots/cur_*.png): 카드마다 본문 길이가 달라 가격 시작선과 CTA 높이가 어긋남. 카드2 에만 CTA 아래 링크 1개. 카드3(의뢰) 가격 오기(+400,000원).

안 (전부 행사 30% 할인 활성 상태, 카드1과 2 는 정가 취소선 + 할인가 2단, 카드3 은 할인 없음):
- A2 (채택 후보, 실파일 반영) = CSS Subgrid 5행(대상, 제목, 본문, 가격, CTA) 동기화. 제목 행 아래 정렬 + h2 max-width 9em 으로 세 제목 모두 두 줄. 카드2 링크를 본문 끝으로. 카드3 가격 3행 = 1개 학교 100,000원 / 학교 추가 (학교마다) +50,000원 / 첨삭과 꼬리질문 (학교마다) +100,000원, "학교마다" 는 정가 줄과 같은 자리의 소형 회색 단위 줄. 가격 블록 행 위 정렬(시작선 일치), CTA 행 아래 정렬.
- B = A2 + 가격 블록을 mat 바탕 패널로 묶고 라벨 회색 소형.
- C = A2 + 정가와 할인가 한 줄(금액 h5).
실측(Playwright): A2/B/C 모두 1440과 1024 에서 5행 정렬 오차 0px, 금액 넘침 0. 파일 = shots/{A2,B,C}_{1440,1024,390}.png, 대조군 shots/cur_{1440,1024,390}.png.

요청: A2 를 9렌즈 45점으로 채점(렌즈1≥4, 렌즈8≥3, 렌즈9≥3, 총점 31 = 릴리스 선). B, C 는 A2 대비 우열 한 줄씩. P1(릴리스 전 필수) / P2(다음 회차) 로 나눠 구체 처방(선택자, 값). 카드3 금액이 ink 이고 카드1, 2 할인가가 seal 인 의미 충돌을 판정에 포함. Blind: 셀프 점수 없음. 출력 = 표 1개 + P1/P2 목록, 60줄 이내, 산문과 은유 금지, 가운뎃점 금지.
