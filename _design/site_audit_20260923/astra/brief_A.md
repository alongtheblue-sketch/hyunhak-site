# hyunhak.com 전면 디자인 검열 브리프 (2026-09-23, astra)

너는 hyunhak.com(현학적 연구소, 대입 면접 준비 상품 판매 사이트)의 시니어 UI 디자이너이자 심사자다. 첨부 이미지는 라이브 사이트와 로컬 수정본을 같은 조건으로 렌더한 전면 스크린샷이다. 작업 디렉터리는 이 사이트 리포지토리(읽기 전용)다. 필요하면 index.html, request.html, assets/base.css, assets/announce.css, programs/*.html, _tools/r2_copy.json 을 직접 열어 확인해라.

## 소유자 지시 (원문 요지)
소유자는 홈의 "대학별로 찾기" 구역(대학 타일 12장이 큰 상자에 "2027학년도 대비"와 취소선 가격을 12번 반복하던 것)을 보고 디자인이 매우 나쁘다고 했고, 사이트 전반을 검열해서 디자인이 나쁜 것은 모두 고치라고 했다. 이 검열의 목적은 배포 전 실제 수정이다. 칭찬은 필요 없고 결함과 그 수정안만 필요하다.

## 이미 반영된 로컬 수정 (라이브에는 아직 없음)
1. 대학 타일: 상자 12장 → 괘선 목록 3열(대학 이름 + 캠퍼스 소형 + 화살표). 학년도와 권당 가격은 리드 한 문장으로 옮김. 단일 탭("전체 31") 제거. 파일 index_local_nopop_1440.png 의 "대학별로 찾기" 구역.
2. 팝업: 하단 시트 두 종류(공지, 행사)를 화면 가운데 한 무대로 통합. 의뢰 개시 카드 + 행사 카드 2장, 활성 카드 가운데 + 다른 카드 측면 0.9 축소 반투명, 5초 자동 넘김(정지 단추, 호버, 조작 시 정지), 하단바(오늘 하루 보지 않기, 화살표, n/N, 닫기). 파일 index_local_popup_1440.png, index_local_popup_390.png.
3. 홈 상품 카드 3장을 5행 Subgrid 로 정렬(이건 라이브에도 이미 배포됨).

## 디자인 체계 (기존 토큰만, 새 색과 새 곡률 금지)
- 색: --ink #312E2E(먹) --paper #F4EFE3(한지 본판) --mat #EBE4D4 --card #FFFDF8 --gray #696561 --body #4A4644 --seal #9E2B22(주인: 가격, 점, 오류에만)
- 괘선 --rule(1px hairs) --rule-strong, 그림자는 --shadow-1 none 이 원칙(괘선으로 위계), --shadow-2 는 부유 요소에만
- 곡률 --r-md 4px --r-lg 8px, 간격 --s1 4 --s2 8 --s3 16 --s4 24 --s5 40 --s6 56 --s7 72, 터치 --tap 48
- 서체 Pretendard(본문) + Noto Serif KR(일부 표제) + JetBrains Mono(숫자, 라벨)
- base.css 의 `:where(body.v2)` 접두 규칙 체계를 그대로 따른다

## 요구 산출 (한국어, 3,000단어 이내, 마크다운)
0. 총평 5줄 이내: 사이트 전체에서 반복되는 결함 유형 3~5개.
1. P0 (배포 전 반드시 수정): 면, 요소, 무엇이 왜 나쁜지(원리 한 줄), 수정안(구체 CSS 또는 마크업, base.css 토큰 사용, 가능하면 파일:줄 인용). 개수 제한 없음.
2. P1 (이번 회차 권장 수정): 같은 형식.
3. P2 (다음 회차): 한 줄씩.
4. 면별 표: 면 이름 | 가장 큰 결함 1개 | 판정(그대로 / 수정 / 재설계).
5. 새로 반영된 3건(타일 목록, 팝업 무대, 상품 카드)에 대한 판정: 통과 / 수정 조건부 통과 / 재작업, 근거와 수정안.
6. 폰(390) 전용 결함: 터치 타겟 48 미만, 넘침, 줄바꿈, 하단 고정 탭과 겹침.

## 규칙
- 사실 진술만. 은유, 비유, 경구체, 대구 문장 금지. 가운뎃점(·)과 em 대시(—) 금지.
- 수정안은 기존 컴포넌트와 토큰을 재사용한다. 라이브러리 추가, 프레임워크 교체, 전면 리브랜딩 제안 금지.
- 판단 근거가 이미지에서 확인되지 않으면 "이미지 근거 없음, 코드에서 확인"이라 적고 파일을 열어 확인해라.
- 각 P0/P1 항목은 소유자가 그대로 적용할 수 있게 셀렉터와 값을 완결된 형태로 써라.
