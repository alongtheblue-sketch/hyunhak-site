### 11.1 판매 경로는 정적 페이지가 아니라 DB 였다

```
cd ~/Workspace/hyunhak-api && env -u HTTP_PROXY -u HTTPS_PROXY -u http_proxy -u https_proxy \

  --command "UPDATE products SET status='inactive', updated_at=datetime('now') WHERE sku='envelope-mock'"
```
