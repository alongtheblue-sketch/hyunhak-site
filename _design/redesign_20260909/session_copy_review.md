# 본 세션 카피 원장 v6 중간 검토 (07:1x, 구현 완료 뒤 R2b 다듬기 발주에 승계)

사실·안전 축: 통과(원장 밖 수치 0, RD-4 미확정 6건 단정 0, style_gate A. E-2 는 BB-14 합쇼체 유지 결재로 면제, E-1 은 UI 짧은 문안 원장 성질).

마케팅 축에서 약한 자리(구현 뒤 R2b 로 고친다):
1. home_h1 「대입 면접 준비」 = 범주 라벨. 학원 사이트 H1 은 무엇을 어떻게 하는 곳인지 한 문장이어야 한다. 후보: 「대학별 면접을 그 대학의 요강과 기출로 준비합니다」(승인 v5 H1 축약, 근거 G5·S2) 또는 「31개 대학 서류기반 면접과 연세대, 고려대 제시문 면접을 준비합니다」(G1·S1).
2. 스튜디오 카드 가격 행이 「지문 1편 33,000원」 하나 = 대칭을 위해 주력 상품(단위 전권 495,000원, 한 편에 16,500원)이 빠짐. 카드에 두 행(낱권·단위 전권) 또는 단위 전권을 첫 행으로.
3. 카드 본문 2줄이 목차 수준(「…을 담았습니다」). 구매 동기 문장 1줄 필요: 가이드북 = 「내 생기부에서 나올 질문을 대학 기준으로 뽑습니다」(G4 전환 규칙) / 스튜디오 = 「고사장과 같은 규격으로 응시하고 첨삭 세 단을 받습니다」(S1·S4).
4. maker_text 「현학자가 두 상품을 같은 기준으로 편집합니다」 → 신뢰 칸은 직함이 앞: 「입시 컨설턴트 13년차 한 사람이 편집합니다」(A1, 13년차 노출은 홈 1곳 규칙 안에서 이 칸으로).
5. faq_source_a 「질문 3,865개를 수록했습니다.」 = 질문에 대한 답이 아님(출처를 물었는데 수량). 「대학 공개 자료와 면접 후기에서 고른 질문입니다.」(G5).
6. studio_h1 「연세대, 고려대 제시문 면접 스튜디오」 = 상품명 반복. 승인 v5 「연세대, 고려대 제시문 면접을 실전 규격으로 연습합니다」가 낫다.
