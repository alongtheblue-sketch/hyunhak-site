# SECTION_MAP_C — 비교 근거형

한 줄 정의: **고를 것부터 갈라 주고, 값과 조건을 표로 맞대어 놓는다.**
구조 특징: 표가 세 벌 연달아 온다. 두 상품 비교 → 구성 또는 절차 표 → 이용권 비교. 서사 절은 없다.
비교 대상은 **자사 상품끼리**로 한정했다. 타사 대비 표현은 표시광고법 위험이라 쓰지 않았다.
