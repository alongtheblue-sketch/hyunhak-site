# 발주 r1: 현학적 연구소 「제시문 면접 스튜디오」 홍보물 2종 디자인 (astra 수석 디자이너)

너는 이 홍보물 2종의 수석 디자이너다. 발주자(현학적 연구소 대표, 이루리학원 부원장) 지시 원문: "현학적 연구소 면접스튜디오 상세페이지 활용해서 인스타 스토리 홍보이미지랑 브로슈어 2p짜리 디자인해줘. astra한테 맡겨."
상세페이지(판매 면)는 이미 라이브다. 그 내용과 사실값을 바탕으로 SNS 세로 이미지 1장과 A4 앞뒤 2면 브로슈어를 만든다. 렌더, 채점, 납품은 발주 세션이 한다. 너는 HTML/CSS 와 설계 노트를 쓴다.

### 1.4 카피 규칙 (브랜드 톤 deadpan)

- 카피의 원천은 `inputs/studio_snapshot_20260920.html` 하나다. 그 안의 문장과 수치를 그대로 쓰거나 줄여 쓴다. 새 주장, 새 수치, 새 혜택을 만들지 않는다. §1.5 표 밖의 숫자는 쓰지 않는다.
- 문장 종결은 **명사형 우선**. "-합니다" 는 상세페이지 원문 인용에 한해 허용. "-한다" 종결 지양.
- 대구(「X 아닌 Y」, 「A는 B, C는 D」식 병렬 경구) 금지. 가운뎃점 기호와 em 대시 기호 0건, 쉼표와 마침표만. 느낌표 0건. 이모지 0건.
- 최상급, 합격 보장, "1위", "유일", "완벽", "국내 최초" 0건. 경쟁 학원 언급 0건.
- 장식용 영문, 로마자 카피 0건. URL 과 이메일만 로마자 허용.
- 형식은 학술적으로 지키고 내용은 사실만 적는다. 감탄, 권유형 구호("지금 바로!") 금지. 버튼형 문구는 "-하기" 허용(예: 자세히 보기).
- 기간 한정 문구(「9월 30일까지 전 상품 30% 할인」)는 **스토리 한 방향에만** 원문 그대로 허용. 할인가를 계산해 적지 않는다. 브로슈어에는 기간 한정 문구를 넣지 않는다(오래 쓰는 인쇄물).

## 2. 매체별 요구

### 2.1 인스타그램 스토리 (`story.html`)

- 캔버스 고정: `html, body { width: 1080px; height: 1920px; margin: 0; overflow: hidden; }`. 스크롤과 넘침 0.
- 세이프존: 위 250 px, 아래 340 px 에는 글자, 로고, 버튼형 요소를 두지 않는다(앱 UI 와 답장 창이 덮는다). 배경 사진이나 색면만 지나갈 수 있고, 배경 사진 `<img>` 에는 `data-bleed="bg"` 를 붙인다.
- 링크 스티커 자리: 아래 세이프존 바로 위, 폭 1080 × 높이 약 160 px 를 비워 두고 HTML 주석 `<!-- link sticker zone -->` 로 표시한다. 스티커는 발행자가 앱에서 붙인다. 지면 안에 가짜 버튼을 그리지 않는다. 대신 "자세히 보기" 를 유도하는 문구 1줄은 그 위에 둘 수 있다.
- 글자: 본문 36 px 이상(권장 38~48), 캡션과 URL 32 px 이상, 헤드라인 80 px 이상(권장 88~120), 헤드라인 자간 -0.04 em 행간 1.15~1.25, 본문 자간 -0.01 em 행간 1.5~1.6. 좌우 여백 80~96 px, 세로 간격은 8 px 배수. 본문 굵기는 400 이상(300 은 헤드라인 장식에도 쓰지 않는다). 가운데 정렬은 3줄 이하 덩어리에만, 그 이상은 왼쪽 정렬.
- 정보량 상한: 헤드라인 1 + 보조 문장 1 + 사실 숫자 3개 이내 + 브랜드 락업 1 + `hyunhak.com` 1. 이 이상은 넣지 않는다. 3초 안에 읽혀야 한다.
- 색면: 玄墨 필드형(밝은 글자) 또는 楮紙 시트형(먹 글자) 중 택. 朱印은 1점 이내(가격 숫자 또는 판매 표시점).
- 사진 사용 여부는 방향마다 다르게 한다(예: 한 방향은 사진 없이 타이포와 숫자, 한 방향은 앱 화면 1장 크게, 한 방향은 배경 무드 사진 위 시트). 사진 위 글자는 대비 4.5:1 을 확보한다. 사진 위 가독을 위한 스크림은 검정 단색이 투명으로 풀리는 세로 그라데이션(최대 불투명 40 %) 하나만 허용하고, 글자 그림자만으로 가독을 만들지 않는다.
- 유채색은 朱印 1종뿐이고 면적 5~10 % 이내. 나머지는 玄墨, 楮紙, 灰墨의 무채 관계로 푼다. 이미지 안에 글자를 굽지 않는다(모든 글자는 HTML 텍스트).

### 2.2 브로슈어 (`brochure.html`)

- 구조: `<section class="page">` 정확히 2개. `@page { size: 216mm 303mm; margin: 0; }`. `.page { width: 216mm; height: 303mm; overflow: hidden; position: relative; page-break-after: always; break-after: page; }`. 마지막 page 는 `page-break-after: auto`. `html, body { margin: 0; }`, `* { -webkit-print-color-adjust: exact; print-color-adjust: exact; }`.
- 재단선은 사방 3 mm 안쪽(210 × 297). 블리드까지 나가는 것은 배경 색면과 배경 사진뿐이다. 글자와 로고는 아래 판면 여백 규칙을 따른다(재단선 안 5 mm 안전선은 자동 충족).
- 판면 여백(발주자 직접 규칙): **재단선 기준 4방 동일 20 mm**(상 = 하 = 좌 = 우, 허용 오차 ±1.5 mm). 모든 static 콘텐츠(글자, 표, 로고, 사진)는 이 판면 안에 둔다. 예외는 `position:absolute` 풀블리드 배경 색면과 배경 사진뿐이다. 판면 박스는 `.page > .wrap { position:absolute; inset: 23mm; }`(블리드 3 + 여백 20) 같은 고정 상자로 만들고, 그 안에서 flex 나 grid 를 쓰되 `.wrap > * { flex-shrink: 0; }` 로 묵시 수축을 막는다(수축하면 잘림이 게이트에 안 잡힌다). 바닥 정렬을 위해 `margin-top:auto` 로 밀지 않는다. 콘텐츠가 넘치면 패딩을 깎지 말고 내용을 줄인다.
- 그리드: 판면 안 6 또는 8 컬럼, 거터 4~6 mm(여백 ≥ 거터 × 2). 본문 9.5~10.5 pt, 행간 1.7(160~175 %), 자간 -0.025 em, 한글 행 길이 25~40 어절. 제목 자간 -0.04 em, 행간 1.3, 타입 스케일 1.414, 디스플레이 : 본문 크기비 2:1 이상. 위계는 크기와 굵기로 만들고 색만으로 만들지 않는다. 캡션 7.5 pt 이상, 사업자 정보 7 pt 이상, 괘선 0.25 pt 이상. `widows: 3; orphans: 3`. 박스 간 간격은 한 값(5 mm)으로 통일, 박스 내부 패딩 상 5.5 / 좌우 8 / 하 5 mm.
- 한글 줄바꿈: `word-break: keep-all; overflow-wrap: break-word` 를 본문과 제목 전체에. `overflow-wrap: anywhere` 는 URL 과 이메일에만.
- 표: 전체 격자와 머리행 배경색 금지. 수평 괘선 3선(머리 위, 머리 아래, 표 끝)만, 필요하면 행 사이 헤어라인 0.25 pt. 숫자는 오른쪽 정렬 + `tabular-nums`. 텍스트 열은 왼쪽 정렬.
- 앞면은 hero 가 하나다(큰 제목 구절 또는 사진 하나 중 택 1). 앞면의 시각 zone 은 제호, hero, 부제, 숫자 밴드, 브랜드 시그니처 다섯을 넘지 않는다. 뒷면은 정보 밀도는 높되 표와 문의 블록이 스캔되기 쉬운 가장 조용한 면으로 만든다(문의와 QR 이 anchor).
- 잡지 요소 금지: Vol., Issue, No., 시즌+연도(예: FALL 2026), 발행호, 목차, 에디터의 말, 다음 호 예고, 신문풍 3~4단. 표기는 발행년도(2026)만 허용.
- 색 면적: 楮紙 바탕 기본. 玄墨 밴드나 玄褐 면은 한 면의 40 % 이내. 朱印은 가격 숫자와 점에만.
