# 제시문 면접 스튜디오 r2, 확정 방향 F

## 확정 방향 개념, 세 줄

C의 무드 사진 위에 불투명한 종이 시트를 유지하고, 세리프 제목을 시선 중심에 둔다.
A의 먹 밴드와 네 단계 절차를 인쇄물의 뼈대로 삼고, 390을 먼저 읽는 두 단계 숫자 위계를 두 매체에 공유한다.
B의 다섯 구역 구성과 조용한 삼선 표를 받아, 뒷면은 응시 단위에서 이용권, 첨삭, 질문, 문의로 읽는다.

## 파일과 작업 범위

| 파일 | 기반과 역할 |
|---|---|
| `dirF/story.html` | r1 C를 복사한 일반 스토리 |
| `dirF/story_promo.html` | 같은 스토리에 지정 할인 문구 한 줄과 소형 점만 추가 |
| `dirF/brochure.html` | r1 A를 복사한 앞뒤 두 면 |
| `dirF/style.css` | A CSS 복사본을 수리, C 스토리와 B 표 장치 통합 |

r1 및 inputs의 86개 파일 SHA-256이 작업 전후 동일하다. 외부 자산, 새 이미지, JavaScript, 브라우저, 렌더, git 명령을 사용하지 않았다. 아래 좌표는 CSS 설계값이며, 글자의 기준선과 폭은 원본 TTF 메트릭을 이용한 정적 추정이다. PDF 페이지 수, 실제 넘침, 폰트 임베드, Type 3 여부는 발주 세션의 렌더 검사 대상이다.

## 스토리 시선 순서와 좌표

시선 순서: 무드 사진 → 제목 → 앱 답변 화면이라는 보조 문장 → 390, 12, 무료 1회 → 이용권 유도 문구 → 발행자가 붙이는 링크 스티커. 로고와 URL은 시트 상단에, 할인 문구는 기존 빈 상단 자리에 둔다.

캔버스 원점은 좌상단, 단위는 px. 일반본과 할인본은 동일 좌표를 쓴다.

- S6은 (b)를 선택했다. 사진 위치는 r1 C와 동일하게 유지하고, 보조 문장을 「답변 화면에서 녹음과 녹화, 첨삭 세 단」으로 교체했다. 사진의 방송용 카메라가 앱 기능의 실제 촬영 장비를 뜻하지 않도록 문장으로 응시 위치를 밝힌다.
- S7의 불투명 종이색은 그대로다. 스크림, 그림자, 사진 리컬러는 없다. S4는 문장만 두며 가짜 버튼을 만들지 않았다.

## 브로슈어 정보 배치 지도

작업면 216 × 303mm, 재단 210 × 297mm, 사방 블리드 3mm. `.page > .wrap`은 `inset:23mm`로 170 × 257mm, 재단 기준 사방 여백 20mm다. 아래 좌표는 작업면 원점 기준 mm이며 각 구역 폭은 170mm다.

### 앞면, 다섯 구역

| 순서 / 선택자 | x / y | 높이 | 정보 배치 |
|---|---|---:|---|
| 제호 `.mast` | 23 / 23 | 10 | 서비스 이름과 대학 부제. 상단 URL 삭제 |
| hero `.front-hero` | 23 / 38 | 30 | 36pt 세리프 H1 하나. 먹 밴드는 원래 높이 67mm 유지 |
| 설명과 절차 `.walkthrough` | 23 / 73 | 115 | 부제 한 줄. 아래 왼쪽 두 컬럼에 타이머 크롭, 오른쪽 여섯 컬럼에 절차 4 |
| 숫자 `.metrics` | 23 / 193 | 35 | 390세트 28pt, 나머지 다섯 숫자 17pt, 라벨 8.5pt |
| 시그니처 `.signature` | 23 / 233 | 47 | 만든 사람 원문. 27mm 락업과 운영 경력, URL을 하단 정렬 |

행 높이 10 + 30 + 115 + 35 + 47, 구역 간 5mm × 4 = 257mm. 설명 구역 안은 부제 10mm + 간격 5mm + 도판/절차 100mm다. 절차 행은 20 / 30 / 20 / 15mm와 간격 5mm × 3. 절차 2 아래에 연세대 8/5/2, 고려대 21/7/3을 두 줄로 흡수하여 별도 고사장 표 구역을 없앴다.

숫자 밴드는 첫 칸 38.75mm, 나머지 각 21.25mm, 거터 5mm다. 숫자는 C 세로 레일에서 가져온 두 단계 크기를 A의 가로 밴드에 적용했다. 큰 390 하나와 작은 다섯 개로 위계를 만든다. 마지막 라벨의 정적 폭은 약 19.64mm로 21.25mm 안에 들어간다.
