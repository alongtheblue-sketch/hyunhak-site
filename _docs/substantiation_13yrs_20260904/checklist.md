# 표시광고법 제5조 실증자료 준비 체크리스트 (GS-16-3): 2026-09-04 s45

> 결재 = 건우 2026-09-04 "모두 권고사항대로 GO" (§GBSTD-20260904-L GS-16-3, 권고 = 준비 착수). 준비 주체 = 건우. 본 문서는 무엇을 어디에 모을지의 목록이다.
> 근거 = 표시ㆍ광고의 공정화에 관한 법률 제5조 ①(사업자는 자기가 한 표시와 광고 중 사실과 관련한 사항을 실증할 수 있어야 한다) ③(실증자료 제출 요청을 받은 날부터 15일 이내 제출) ⑤(미제출 상태로 계속 광고하면 중지 명령 가능). 조문 원문 = law.go.kr (legal-contract-privacy-analyst 09-04 메모).

## 1. 실증 대상 표현 (원천 재생성 census)

`python3 census_claims.py` 가 사이트 HTML 전면 + 네이버 광고 계획 JSON + 인스타 광고 계획 MD 를 훑어 `claims_census.md` 를 다시 만든다. 사업장 주소 표기(테헤란로, bizinfo, streetAddress)는 광고 표현이 아니라 제외. 정적 목록을 손으로 들고 다니지 않는다(09-04 s44 메모의 게재 목록은 programs/yonsei, korea, studio 와 b2b 를 빠뜨렸다).

| 종류 | 표현 | 실증 문서 | 판정 규칙 |
|---|---|---|---|
| 연차 | "13년차", about `13 입시 컨설턴트 연차`, `13년차` 숫자 블록 | ① 최초 입직 증빙(최초 근로, 위촉계약서, 4대보험 자격취득 이력) ③ 현 재직증명서 ⑤ 연차 산정표 | 연차 = 최초 입직일부터 게재 시점까지의 햇수. 공백 기간이 있으면 산정표에 적고 포함 여부를 변호사와 정한다 |
| 지역 | "대치동 입시 컨설턴트" | ② 현 재직 학원 재직증명서(사업장 주소 대치동) + 연구소 사업자등록증(주소 대치동 H 타워) | 재직처 또는 사업장이 대치동 소재 |
| 직위 | about "대치OOO학원 부원장" | ② 재직증명서 직위란 | 문서상 직위와 일치 |
| 학력 | "고려대학교 영어교육과 졸" | ④ 졸업증명서 | 학과명 일치 |
| 경력 8건 | about 경력 목록 8행 | ③ 건마다 계약서, 위촉장과 출강 확인서와 출제위원 위촉 문서 | 문서 없는 건은 문면을 걷거나 "확인 가능한 범위"로 좁힌다 |

## 2. 준비 목록 5종 (건우)

- [ ] 1 최초 입직 증빙: 최초 근로계약서 또는 위촉계약서, 4대보험 자격취득 이력(국민연금과 건강보험 가입 이력 조회서)
- [ ] 2 현 직위 증빙: 대치동 소재 학원 재직증명서(직위 "부원장", 사업장 주소 표기)
- [ ] 3 경력 8건 문서: `tenure_table.csv` 의 경력 1~8 행마다 파일명 기입
- [ ] 4 학력 증빙: 고려대학교 영어교육과 졸업증명서
- [ ] 5 연차 산정표: `tenure_table.csv` 시작일과 종료일 채움, 공백 기간 표시. 연차가 바뀌는 날(매년 최초 입직일)에 사이트 "13년차" 문면을 일괄 갱신하고 `census_claims.py` 로 구 연차 잔존 0 확인

## 3. 보관 규칙

- 증빙 파일은 개인정보(주민번호, 주소와 급여)를 담는다. **리포에 넣지 않는다.** `evidence/` 는 `.gitignore` 로 제외했고, 원본은 건우 개인 보관(iCloud 개인 영역), 리포에는 `tenure_table.csv` 의 파일명만 남긴다.
- 제출 요청이 오면 접수일을 `tenure_table.csv` 비고에 적고 15일 이내 제출(제5조 ③). 접수일 + 15일이 지나도록 제출 못 하면 광고를 먼저 내린다(⑤).

## 4. 남은 판단 (변호사, 의뢰서 §3-③)

- 연차 산정에서 프리랜서와 파트타임 기간, 공백 기간의 포함 여부.
- "13년차" 를 "13년째" 나 "2014년부터" 같은 확인 가능한 문면으로 바꾸는 것이 실증 부담을 줄이는지.
- 지역 표현을 재직처 기준으로 두는 것과 연구소 사업장 기준으로 두는 것 중 어느 쪽이 안전한지.
