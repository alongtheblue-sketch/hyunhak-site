# SEO 제목 원장 2026-09-03, 검색 유입 축 개편 (hyunhak.com)

생성: `python3 _tools/build_guidebook.py seo` (guidebook/ 39면) + 손편집 6면 (index, programs 4, support). 값의 SoT 는 `_tools/seo_manifest.json`, 골격과 SEARCH 표의 SoT 는 `_tools/build_guidebook.py`. 이 문서는 그 결과의 기록이다.

## 1. 규칙

- 검색어 정합: title 맨 앞 = 짧은 대학명 + 대표 전형명 + 면접. 전형명은 `SEARCH` 표(build_guidebook.py)에 손으로 고른 검색어형 표기이며, `ground_check()` 가 meta v3 `tracks[].track` 과 `spec_tracks` 문자열에 실재하는지 대조한다(공백, 괄호, 로마숫자 무시). 없으면 빌드가 선다.
- 길이: description 70~110자, answer 40~110자, FAQ 답 40~110자. `_fit()` 이 긴 후보부터 차례로 시도하고 범위 밖이면 정지한다(조용한 초과 금지).
- 금지: 가운뎃점, em대시 0. 합격률, 만족도, 최고, 1위, 유일 같은 실증 없는 표현 0.
- 저자 신뢰 문구: "13년차 대치동 입시 컨설턴트" (about.html "대치OOO학원 부원장, 입시 컨설턴트 13년차" 근거).
- 가격: 33,000원(권당, 카탈로그 최상위 price), PDF 소장판 110,000원(products_status.json), 스튜디오 전권 495,000원과 지문 1편 33,000원(manifest programs/*.html offers). 비판매 7권은 title, description, answer 에 가격을 넣지 않는다.
- 유형 판정 순서 `seo_type()`: 스튜디오 2권(yonsei, korea) = e1 -> 비판매 = e2 -> med 보유 = b -> edu 보유 = d -> alt 보유 = c -> a. 재외국민, 외국인 전용 제시문 전형은 alt 로 치지 않는다(sungshin, cau, inha, pusan, knu). 동아대 실기 발표 혼합형은 제시문이 아니라 a.
- 홈(index.html)과 스튜디오 LP 2면의 answer 는 빈 값 유지: 히어로 리드가 직답(_docs/SEO_GEO_AEO.md §4). 두 면 모두 `.pagehead` 가 없어 aeo 단락이 `<main>` 첫 자식(히어로 앞)에 끼어든다.
