### 결제창 실검증 (2026-09-01 18:2x~19:0x, 로컬)

8799 dev 서버를 포트원 모드로 재기동하고(`--var PG_PROVIDER:portone`) 로컬 사이트 8788 에서 회원 세션으로 결제창까지 실제로 열었다.

**첫 호출에서 결함 1건이 잡혔다.** 결제 버튼을 누르자 포트원 prepare API 가 400 을 반환하고 결제창이 열리지 않았다.

```
POST https://checkout-service.prod.iamport.co/api/prepare/v2  →  400
alert: 결제 창 호출에 실패하였습니다.
       이니시스 V2 일반 결제의 경우 구매자 휴대폰 번호는 필수 입력입니다.
```

원인은 `portoneDriver` 의 `customer` 객체에 `phoneNumber` 가 없었던 것이다. 서버 통합 테스트 9건은 우리 API 와 포트원 스텁 사이만 덮으므로 이 결함을 볼 수 없다. 결제사 SDK 가 요구하는 클라이언트 파라미터는 실브라우저 호출만이 게이트다.

미검증으로 남은 것.

- **실제 승인까지는 가지 않았다.** 결제창 표시까지만 확인하고 카드번호는 넣지 않았다.
- **결제창 취소 후 버튼 복구.** 결제창의 X 를 누르면 이니시스 취소 확인 창이 뜨는데, 그 확인 버튼이 자동화 클릭에 반응하지 않아 취소 경로를 끝까지 못 봤다. 코드에는 `catch` 에서 버튼을 되살리는 처리가 있다(`USER_CANCEL` 판정 포함). 사람이 마우스로 눌러 확인할 사항이다.
- 가상계좌와 계좌이체 수단은 결제창을 띄우지 않았다. 카드 경로만 확인했다.
